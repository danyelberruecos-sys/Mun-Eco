# MunEco
## Descripción
Sistema de gestión de residuos, campañas ambientales y eco puntos para la Universidad.
## Requisitos
- Java 26
- Eclipse
- Maven
## Como importar el proyecto
1.En Eclipse, selecciona File → Import → Maven → Existing Maven Projects, y clona o descarga previamente el repositorio desde GitHub usando su URL.

2.Selecciona la carpeta del proyecto clonado, Eclipse detectará el pom.xml automáticamente y cargará el proyecto listo para ejecutarse.

## Al momento de ejecutarse
El proyecto no hace uso de arreglos, esta cubierto en su totalidad por ArryLisyts. Por este motivo no hay necesidad en ningún momento de declarar la capaciddad de dichos arreglos.
Al ejectar el codigo se encontrara con un menú principal, con el cual se interactua digitando el número de la acción que desea realizar. La octava opcion del menú principal cargara objetos de prueba los cuales puede tomar como base para seguir interactuando con el programa.
